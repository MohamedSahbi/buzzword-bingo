# Backlog

Ideas agreed with Mohamed, roughly in priority order. Move an item to the README once it ships.

## Advent calendar
- **Prediction rooms on the final door** (24 Dec in Czech, 25 Dec in English): set up a few days ahead, sealed predictions, the host starts the event, claims with 👍/👎 votes, "best prophet" awards. *In progress.*
- **"Anděl, nebo čert?"**: a quick-fire game for people who can't wait for the next door. Twenty everyday deeds ("Snědl poslední rohlík v kuchyňce") flash up; sort each into 😇 or 😈 in 3 seconds; points for agreeing with Mikuláš's book; in a team, see how colleagues judged.
- **"Play together now"** on any door: turns it into a live shared room for a team call.
- **Practice calendar chats** in the new human style (only door 1 so far).
- More cultures (see Languages).

## Game modes
- **Prediction bingo as a permanent room type** next to buzzword bingo (players write the squares; claims and votes).
- **Daily meeting card**: one shared card per day and language, Wordle-style spoiler-free share, streaks.
- **Golden square** in normal bingo (bonus points).
- **Team inside-joke packs**: custom squares mixed into a room's card.
- **Escalation**: corporate 2048 (Email → Ping → … → Reorg), Christmas edition. Not bingo; maybe a separate mini-game.
- **Custom topics + AI generation** (Gemini free tier via Firebase AI Logic, behind App Check).
